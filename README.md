## 🚀 Getting started

```bash
git clone https://github.com/MoSalah-2002/NLP-Experiments.git
cd NLP-Experiments
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
jupyter notebook
```

You can also open notebooks directly in Google Colab. Check each notebook's first cells for dataset and checkpoint requirements; external datasets are not bundled.

## 🔐 Security

Secrets have been removed from the prepared notebook copies where detected. Provide your own credentials through environment variables when needed. Never commit API keys, access tokens, or private datasets.

## 📌 Scope & reproducibility

These are independent learning experiments, not a single production package. Results depend on the source dataset, preprocessing, checkpoint, library versions, and runtime. Not every notebook has been executed end-to-end in a clean environment.
