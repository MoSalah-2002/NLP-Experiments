## 🚀 Getting started

```bash
git clone https://github.com/MoSalah-2002/NLP-Experiments.git
cd NLP-Experiments
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
```

Open any notebook with Jupyter or Google Colab. Some notebooks expect datasets or model files that are not included; update their paths before running.

## 🔐 Credentials & data safety

Credentials found in the source notebooks have been removed and replaced with environment-variable references where applicable. Set your own keys locally (for example `HF_TOKEN` or `API_KEY`) and **never commit secrets**. Datasets are not redistributed in this repository.

## ⚠️ Notes

- This is an educational and experimental portfolio, not a single packaged NLP library.
- Results depend on the dataset, preprocessing choices, model checkpoint, and runtime.
- Notebooks are provided as research/learning artifacts; some cells may require adaptation to current library versions.
